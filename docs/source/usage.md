# Usage

## Quick Start

Import the `add_one` function and call it with a number.

```python
from example_package_ShotaDeguchi.example import add_one

result = add_one(1)
print(result)
```

Output:

```text
2
```

## Function Reference

The `add_one` function adds one to the given number.

For details about its parameters and return value, see the [API Reference](api.md).
